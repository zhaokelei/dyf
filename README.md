# 基于郑州工商学院德育分统计办法的德育分后台管理系统

**简体中文** | [English](README.en.md)

基于郑州工商学院德育分统计办法构建的德育分后台管理系统，用于学生德育材料的申报、审核、成绩归档与统计分析。项目源码直接位于仓库根目录，采用 **Laravel 13 + PHP 8.4 + MariaDB/MySQL + Vue 3 + Inertia + Vite + Tailwind CSS 4**，支持 PC 与手机端响应式界面。

> 历史 Flask 版本已归档，不再包含在仓库中；安装、使用与二次开发均以当前仓库内容为准。
>
> **安装部署请先阅读 [INSTALL.md](INSTALL.md)**，内置 Web 安装向导位于 `/install.php`。

---

## 功能概览

- **学期与学年**：每学年包含两个学期，申请与成绩按学期归档；排行榜、个人成绩与统计支持按学期或学年汇总。
- **申请流程**：学生个人申请与教师集体申请，支持审核通过/驳回、核定分值修改、撤回、删除与分值扣回。
- **证明材料**：支持多张图片（JPG / PNG / WebP）上传，审核端提供图集与在线预览。
- **扣分申诉**：学生可对扣分记录提交申诉理由与图片证明；申诉通过后记录标记为已撤销，并保留审计痕迹。
- **排行榜**：全校、学院、年级、班级排行；支持周、月、自定义日期、学期与学年汇总；可按专业、姓名/学号筛选，并导出带当前范围与周期的 Excel。
- **数据统计**：类别分布、学院分布、近 12 个月申请趋势、德育分前十名与周期切换。
- **组织层级**：学校 → 学院 → 专业 → 年级 → 班级；专业仅作为查询与统计维度。
- **分级权限**：学生、教师、辅导员（`class_admin`）、学院管理员、系统管理员按授权范围访问数据。
- **公告与设置**：公告支持弹窗提醒；系统名称、基础分、注册开关等可在系统设置中维护。
- **响应式界面**：桌面端深色可折叠侧栏，移动端底部导航与卡片布局，支持减少动态效果。

## 评分模型

- 默认**基础分** 40 分，可在系统设置中调整。
- **总分 = 基础分 + 加分 − 扣分**，最低 0 分，不设上限。
- **主类别**与**子类别**分别设置分值上限；同一学生同学期同类别可存在多条有效记录。
- **任职分**只取最高一项，不累加。
- **志愿服务**按专门规则计算：每 4 次符合条件的志愿服务自动加分，并受学期上限约束。
- 支持 0.5 分（半分）记录，后端校验与前端表单均已适配。

## 环境要求

- PHP **8.4**，启用 Laravel 所需扩展（`pdo_mysql`、`mbstring`、`openssl`、`fileinfo`、`zip` 等）
- MySQL **5.7+** 或 MariaDB **10.3+**
- Composer 2
- Node.js 20+ 与 npm（构建前端资源）

## 快速开始

### 方式一：Web 安装向导（推荐）

1. 上传项目，并将站点根目录指向 `public/`。
2. 确保 `storage/` 与 `bootstrap/cache/` 可写。
3. 访问 `https://your-domain/install.php`，依次完成环境检测、数据库配置、数据初始化与管理员创建。
4. 安装完成后向导写入 `storage/installed.lock` 并自动锁定。

### 方式二：命令行安装

```bash
composer install
cp .env.example .env
php artisan key:generate

# 配置 .env 中的数据库连接后：
php artisan migrate --seed
npm ci
npm run build

php artisan serve
```

系统不预置默认管理员账号或默认密码，请在安装过程中创建首个管理员。

## 角色与权限

| 角色 | 权限范围 |
|------|----------|
| **学生** | 本人申请、成绩、扣分申诉、涉及本人的集体申请、公告 |
| **教师** | 集体申请、成员明细、类别管理、只读排行榜、公告 |
| **辅导员（`class_admin`）** | 授权年级/班级范围内的学生、个人申请审核、成绩、申诉、排行榜与统计；不可创建用户、不可审核集体申请 |
| **学院管理员** | 授权学院内的全部业务，含教师、专业、班级、集体申请审核与辅导员班级配置 |
| **系统管理员** | 全校组织配置、学院管理员授权、用户管理、全部审核、统计与系统设置 |

所有列表、统计、导出、审核与申诉均按授权范围过滤，跨范围访问返回 **403**。
